# Beat Desk｜節拍工作台

不需帳號或付費。在本機匯入有權處理的音檔，估計 BPM、比較半拍／倍拍、以耳朵跟拍或輸入自己採用的速度，安排曲目與起播點。示範是程式即時合成的原創節奏，沒有商用錄音、外部素材、串流下載或遠端 AI。

## 使用

以靜態網站伺服器開啟本目錄，例如執行 `python3 -m http.server 8000 --bind 127.0.0.1`，然後瀏覽 localhost:8000。直接用 file:// 開啟可能被瀏覽器的模組安全限制阻擋。首次完整載入後可在支援 Service Worker 的 localhost 或 HTTPS 瀏覽器中離線重開。無外部字型、依賴或分析追蹤。

匯入多首音檔或選「試聽示範」。選取歌單一列，在左側播放、跟拍或校正。按上／下箭頭把目前顯示的順序轉為手動順序；速度落差模式從第一首起，逐首接最接近的已知 BPM，並非全域最佳化。兩種排序及 CSV 都採用校正後 BPM；差值不代表調性或轉場相容。起播點只影響此工具的播放，不剪輯音檔。

## 估計與限制

規律、清晰的鼓點通常較適合；弱音、長前奏、自由速度、切分、極短片段與拍號歧義可能需要手動校正。讀取解碼後的實際 sampleRate，最多分析前 60 秒；規律度是對候選間隔一致性的描述，不是答對機率。沒有可靠節拍時不以零冒充。編碼支援取決於瀏覽器。不支援及損壞的音檔仍可手動標示。

歌單 40 首；單檔上限 32 MiB、長度 5 分鐘。逐檔先檢查大小與瀏覽器讀出的長度，再以 Web Audio 解碼；原生解碼器仍需解碼完整檔案，估計器的 60 秒上限並非解碼保證。頁面只暫時持有播放所需的本機檔案參照、縮圖波形；不保存完整 PCM。

## 私隱、離線與匯出

localStorage 只保留標題、檔案識別資訊（名稱、大小、修改時間）、節拍、順序、時長、起播點、分析狀態及筆記。清空歌單可移除這些資料。重新整理後可再選同一原檔以接回播放；音檔絕不傳到主機。Service Worker 只快取應用程式檔案，不快取音訊。CSV 以 UTF-8 BOM 寫出，有引號跳脫及公式前綴防護，不含音訊。

## 驗證

`npm test` 執行無依賴 Node 測試。GitHub Actions 對 push／PR 跑測試和模組語法檢查。可另外以規律 90／120／128／150 BPM、44.1／48 kHz、強弱拍交替的 140 BPM、靜音與無效檔進行瀏覽器驗收。節拍倍數歧義不是調性分析。
